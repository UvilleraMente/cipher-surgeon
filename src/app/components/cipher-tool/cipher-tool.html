How it works

  1. A random 16-byte salt and your password go through PBKDF2-SHA-256 to derive a 256-bit key.
  2. The text is encrypted with AES-256-GCM and a random 12-byte IV, which also adds a tamper-proof tag.
  3. The result is one string: cs1.iterations.salt.iv.ciphertext. The header is authenticated too.

Anyone with the password can decrypt it with this page, the CLI or the npm package. Without it, nobody can, including me.
